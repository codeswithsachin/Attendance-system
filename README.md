# Attendly v2 — Professional Attendance System

This version is a frontend prototype designed to look and behave like a real classroom SaaS product.

## Included

- Teacher login screen
- Student login screen
- Teacher dashboard
- Student portal
- Attendance register
- Present / absent / unmarked states
- Student roster and search
- Multiple classes
- Analytics and class health
- Attendance trends
- Reports and CSV export
- Settings and creator credit
- Demo data
- Responsive mobile layout
- Working navigation and buttons
- Local browser persistence

## Publish

This is a static site, so it can be published to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

For GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Repository → Settings → Pages.
4. Choose Deploy from branch.
5. Select `main` and `/ (root)`.
6. Save.

## Very important

The login in this prototype is NOT real security. Credentials are stored in JavaScript for demo purposes, and attendance is stored in browser localStorage.

For a real school system where teachers and students use the same online data, the next production step is:
- Supabase/Firebase database
- Real authentication
- Server-side authorization
- Classes linked to teacher accounts
- Student accounts
- Password reset
- Secure database rules
- Cloud backups

Do not use the demo credentials as production authentication.

## Creator credit
